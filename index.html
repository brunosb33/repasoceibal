Qué hay que saber para la evaluación

La evaluación tiene cinco tipos de ejercicio. Todos usan las mismas ocho piezas de Python. Si las entiendes y resuelves los cinco ejercicios de la otra pestaña, llegas preparado.

Las reglas de todos los ejercicios

  • Sin definir funciones propias: no se usa def. Sí se usan las de Python: input, int, print, len, range.
  • El bucle que pide la consigna: si dice for, no vale while, y al revés.
  • Nombres y formato exactos: la lista se llama como dice el enunciado y la salida se escribe igual que el formato pedido. Corrige un programa que compara el texto: Suma: 18 está bien; La suma es 18, no.

Las ocho piezas de Python

1. Pedir un número

input siempre devuelve texto; int lo convierte en entero.

edad = int(input("Edad: "))

2. Mostrar resultados

print separa con un espacio lo que va entre comas. Con f se meten variables entre llaves.

print("Suma:", 18)       # Suma: 18
print(f"Nota {1}: {7}")   # Nota 1: 7

3. Decidir con if

== igual, != distinto, > < >= <=. El resto de dividir es %: si n % 6 == 0, n es múltiplo de 6.

if nota >= 5:
    print("Aprobado")

4. Repetir N veces: for

range no incluye el último número. El tercer valor es el paso.

for i in range(1, n + 1):
    print(i)    # 1 hasta n, incluido
for i in range(6, 20, 6):
    print(i)    # 6, 12, 18

5. Repetir mientras: while

Algo adentro tiene que cambiar la condición; si no, el bucle no termina nunca.

i = 1
while i <= 3:
    print(i)
    i += 1      # sin esto, bucle infinito

6. Listas

Guardan valores en orden. Las posiciones empiezan en 0.

notas = []          # vacía
notas.append(7)     # [7]
notas.append(4)     # [7, 4]
print(notas[0])     # 7
print(len(notas))   # 2
print(notas)        # [7, 4]

7. Recorrer una lista

Con for se toma cada elemento; con while se usa una posición i.

for n in notas:
    print(n)

i = 0
while i < len(notas):
    print(notas[i])
    i += 1

8. Acumulador y contador

Los dos empiezan en 0 antes del bucle. Uno suma valores; el otro suma 1 cuando pasa algo.

suma = 0
aprobadas = 0
for n in notas:
    suma += n
    if n >= 5:
        aprobadas += 1

Antes de entregar, revisa

  • ¿El rango incluye el límite cuando el enunciado dice "incluido"?
  • ¿Usaste el operador justo? "Mayor o igual" es >=, "mayor" es >, "menos de" es <.
  • ¿Cada while tiene algo adentro que cambia su condición (un input o un i += 1)?
  • ¿Los acumuladores y contadores empiezan en 0 antes del bucle?
  • ¿La lista empieza vacía y se llama exactamente como pide el enunciado?
  • ¿El valor de corte se pregunta antes del append?
  • ¿Numeras desde 1 con i + 1?
  • ¿El récord se actualiza cuando se supera, y el contador es otra variable?
  • ¿La salida es idéntica al formato pedido, con mayúsculas y dos puntos?
  • ¿Probaste el caso sin datos (lista vacía o meta 0)?
